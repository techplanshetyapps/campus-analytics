An enterprise-grade Python solution built to ingest student queries, audit data quality, perform advanced data preprocessing, analyze support metrics, and leverage Generative AI prompt engineering for automated classification.

---

## Technology Stack & Architecture

* **Core Language:** Python 3.x
* **Data Manipulation & Analysis:** NumPy, Matplotlib
* **Environment:** Jupyter Notebook / Google Colab
* **AI & LLM Orchestration:** Structured Prompt Engineering Templates
* **Data Persistence:** CSV / Relational SQL structure (`student_queries.csv` / `student_queries.sql`)
